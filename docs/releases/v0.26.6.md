# Vortex v0.26.6 · Estabilidad de Spotify

Versión Android: 0.26.6 (42). Actualización centrada en Spotify sobre v0.26.5;
no incluye la fase pendiente del reproductor ni una migración de base de datos.

- Actualiza la lectura paginada de playlists al recurso `/items` y admite los formatos `item` y `track`.
- Continúa después de páginas con canciones retiradas, conserva posiciones y repeticiones intencionales.
- Evita generar una canción ficticia al analizar una colección vacía.
- Limita los reintentos de red y respeta `Retry-After`; las esperas superiores a 30 segundos se notifican sin reintentar anticipadamente.
- Rechaza páginas repetidas o respuestas incompletas antes de reemplazar la biblioteca guardada.
- Propaga la cancelación y libera el indicador de sincronización al terminar.
- Evita seguir redirecciones HTTP cuando se envía un token de sesión.

Se añaden 11 pruebas JVM, incluyendo una playlist simulada de 1.025 entradas.
La validación con una cuenta real de Spotify y en el teléfono sigue pendiente.
Esta actualización no elimina las restricciones de Spotify ni los bloqueos de verificación de YouTube.

## Recuperación

Si aparece una regresión, conservar los datos de la aplicación y distribuir un hotfix
con un versionCode superior. No desinstalar para regresar a una APK anterior: se perderían
los datos locales. Las notas de GitHub incluyen las verificaciones y hashes de las APK publicadas.
