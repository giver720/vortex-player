# Vórtex 0.24.1 · Hotfix de vídeo verde y MP4 compatible

Este hotfix corrige los destellos verdes y cuadros dañados que podían aparecer al iniciar un
vídeo o después del cambio automático de decodificación por hardware a software.

## Inicio y recuperación de vídeo

- VLC abre el medio desde cero para que el decodificador reciba una secuencia válida de cuadros.
- La posición guardada se aplica mediante un salto preciso cuando VLC confirma el estado de
  reproducción, en vez de iniciar el demultiplexor a mitad de un grupo de imágenes.
- Los saltos solicitados durante la carga se conservan y se aplican al comenzar la reproducción.
- El fallback automático de hardware a software mantiene la posición sin reintroducir los
  artefactos verdes del inicio anterior.

## MP4 más compatible

- Las nuevas descargas MP4 priorizan vídeo H.264/AVC y audio M4A para mejorar la compatibilidad
  con decodificadores Android.
- Si YouTube no ofrece esa combinación, el motor conserva rutas de respaldo para completar la
  descarga.
- MKV y WebM mantienen la selección de máxima calidad con AV1 o VP9 cuando esté disponible.

## Calidad

- 70 pruebas JVM en Debug y 70 en Release, sin fallos.
- `lintDebug` y `lintRelease` ejecutados correctamente.
- APK Debug y tres APK Release compilados correctamente.
- APK Release firmados con APK Signature Scheme v2.

## Descargas

- `app-arm64-v8a-release.apk`: recomendado para prácticamente todos los móviles actuales.
- `app-armeabi-v7a-release.apk`: móviles Android antiguos de 32 bits.
- `app-x86_64-release.apk`: emuladores, Chromebooks y dispositivos Intel compatibles.

## Comprobación solicitada

Reproduce desde el inicio el MP4 que antes mostraba verde y prueba también un salto de posición.
La imagen debe aparecer estable tanto en `HW` como después de una recuperación automática a `SW`.
