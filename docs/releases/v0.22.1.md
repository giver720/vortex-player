# Vórtex 0.22.1 · Boost VLC reforzado

Hotfix del sistema de amplificación introducido en 0.22.0.

## Correcciones

- El boost usa ahora la etapa de volumen software nativa de VLC entre 100 y 200 %.
- Los niveles superiores a +6 dB combinan el volumen VLC con preamplificación del ecualizador.
- La protección de la curva ya no cancela la ganancia solicitada al usar presets positivos.
- Al encender el boost con un valor guardado de 0 dB se seleccionan automáticamente +6 dB.
- VLC vuelve a recibir el nivel de boost al iniciar cada pista, evitando que algunos dispositivos
  lo pierdan cuando recrean su salida de audio.
- La interfaz muestra simultáneamente decibelios y el porcentaje real enviado a VLC.

## Verificación

- Pruebas de regresión para 100 %, 178 % y 200 % de volumen VLC.
- Smoke test nativo preparado para confirmar 200 % durante reproducción real.
- Builds Debug y Release verificadas.
