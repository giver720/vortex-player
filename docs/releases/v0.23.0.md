# Vórtex 0.23.0 · Audio Pro, subtítulos y motor inteligente

Esta actualización refuerza tres pilares del reproductor: sonido, subtítulos y estabilidad.

## Audio Pro

- Nuevos perfiles Seguro, Potente, Noche y Voz, además del ajuste personalizado.
- Comparación A/B con «Tono original» sin perder la configuración guardada.
- Indicador preventivo de riesgo de saturación para la curva de ecualización y boost.
- ReplayGain permanente en VLC con protección de picos para medios etiquetados.
- Perfiles independientes por altavoz, auriculares con cable y Bluetooth.

## Centro de subtítulos

- Carga de SRT, WebVTT, ASS y SSA desde el selector de documentos de Android.
- Sincronización de la pista principal entre −60 y +60 segundos.
- Segundo subtítulo SRT/WebVTT simultáneo con retardo, tamaño y fondo independientes.
- Copia limitada a 8 MB en caché privada, sin permisos adicionales de almacenamiento.
- Búsqueda opcional en OpenSubtitles por título y por idioma: español, inglés o ambos.
- Descarga directa como pista principal o secundaria, con cuota restante visible.
- La API key de OpenSubtitles se cifra con Android Keystore y nunca se incluye en el APK.

## Motor de reproducción inteligente

- Búfer adaptativo para archivos locales, HTTP, HLS y RTSP, con perfil de memoria reducida.
- Decodificación hardware en la ruta normal y fallback automático a software cuando falla.
- Watchdog para detectar una reproducción congelada y reabrirla conservando la posición.
- Límite de dos recuperaciones automáticas para evitar bucles infinitos.
- Conservación de velocidad, audio, subtítulos externos y sincronización al recuperarse.
- Nuevo panel con fuente, HW/SW, códec, resolución, FPS, bitrate, cuadros perdidos,
  paquetes dañados y recuperaciones.
- Reintento manual en modo software para medios especialmente problemáticos.

## Calidad

- 60 pruebas JVM en Debug y 60 en Release, todas correctas.
- `lintRelease` sin errores ni incidencias nuevas en los módulos modificados.
- APK instrumentada compilada correctamente.
- Tres APK Release procesadas con R8 y firmadas con APK Signature Scheme v2.

## Descargas

- `app-arm64-v8a-release.apk`: recomendado para prácticamente todos los móviles actuales.
- `app-armeabi-v7a-release.apk`: móviles Android antiguos de 32 bits.
- `app-x86_64-release.apk`: emuladores, Chromebooks y dispositivos Intel compatibles.

## Nota de compatibilidad

Vórtex requiere Android 7.0 o superior. OpenSubtitles es opcional y necesita la API key de una
aplicación creada por la persona usuaria; no se solicitan credenciales de cuenta dentro de Vórtex.
